# Laboratorio 09 - ES6+

## Objetivo
Practicar las características de JavaScript ES6+ mediante ejercicios y la refactorización de código.

## Contenido
- `index.html`: página principal de los ejercicios.
- `js/`: archivos JavaScript de los ejercicios originales.
- `tarea/`: página y módulos de la tarea de refactorización.

## Características utilizadas
- Variables `const` y funciones flecha.
- Plantillas de cadenas.
- Parámetros rest y valores predeterminados.
- Desestructuración y operadores spread.
- Métodos `map` y `reduce`.
- Exportación e importación de módulos ES6.
